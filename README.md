# French vACC Documentation Repository

Welcome to the official collaborative repository for the **French vACC Documentation**.

This repository is designed to support **collaboration, maintenance, and issue tracking** for the French vACC documentation. It contains the **structure and configuration files** that make up each pack, ensuring consistency, realism, and compatibility for controllers.

---

> ⚠️ **Important:**  
> This repository does **not** contain the whole vACC documentation content as some areas are restricted. That said, you can still **contribute to the publicly available documentation** (hosted in this repo) and **report bugs** or send us **suggestions**.

---

## 🐞 Bug Reporting

Did you spot an issue?

- Incorrect frequency  
- Outdated diagrams  
- Spelling
- Broken links  
- General improvements or suggestions  

👉 Please open an issue here:  
https://github.com/vaccfr/vaccfr-docs/issues/new?template=doc-issue.md

Clear and detailed reports help us fix things faster.

## 🤝 Contributing

We welcome contributions from the community. To collaborate:

1. Fork this repository  
2. Make your changes or improvements  
3. Commit and push your updates  
4. Open a Pull Request to the `main` branch for review

> ⚠️ **Important:**  
> Should the document you'd like to create is about ATC Training or ATC Operations, please get in touch with ATC Training Department or Ops & Nav Team.
