# Se connecter en tant qu'observateur

Bienvenue sur cette page ! Ici, nous vous expliquons comment vous connecter en tant qu'observateur (OBS) sur Euroscope afin de réaliser des sessions d'observation.

Cette page vous donne également quelques informations de base sur le fonctionnement d'Euroscope et de CoFrance. Pour des informations plus poussées concernant CoFrance ou Euroscope, consultez les manuels adéquats qui regorgent d'informations.

> Avant de poursuivre, assurez-vous d'avoir suivi la fiche [Installation des outils pour contrôler](https://doc.vatsim.fr/fr/atc-tools).
{.is-warning}


## Lancez le fichier .prf approprié

Lancez le fichier .prf qui convient le mieux pour la position que vous souhaitez observer. Dans cet exemple, nous allons observer une session de contrôle sur "De Gaulle Approche". Il est donc approprié de choisir le profil *EGA Paris-CDG.prf* du pack LFFF.
