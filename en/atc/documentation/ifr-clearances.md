# Delivering IFR clearances

The IFR clearance is an authorisation delivered by the Delivery Controler to IFR flights with a filled flight plan. This clearance contains a number of instructions detailled bellow that must be followed by the departing aircraft.

## Clearance contents
A departure clearance must contains the following elements:
- The name and identifier number of the SID : eg. BUBLI6B
- The initial altitude or flight level : eg. FL120
- The departure runway ; eg. 26R
- The squawk code : eg. 1000

**The SID**
The SID or Standard Instrument Departure, is a specific route linked the departure airport with the first point/fix of a flight plan.
These departure routings are published on charts illustrating the trajectory on a ground projection, they also contain altitude and/or speed restrictions as well as any specific procedures if any exists.

**The initial climb**
The initial altitude or level is confirmed by the Delivery controler even if it is published on the chart, this is done on the network as a mitigation to single pilot operations.

> If the initial climb is an <u>altitude</u>, **you must give the QNH** after the cleared altitude unless the pilot has reported having the latest valid ATIS information when requesting clearance.
{.is-warning}

Once the initial level or altitude is readback the traffic is expected to climb to and maintain this altitude while complying with all restrictions if they exist.

**The departure runway**
This is the runway the pilot can plan for departure.

**The squawk code**
The squawk code is an identification code to be entered in the aircraft's transponder. This code allows the radar controlers (APP & ENR) to correctly identify a radar track.

The code varies depending on :
- Flight rules used
- The destination and overflown zones

## Omnidirectional departures
Even though most airfields in France have published departure routings, some aircraft may not be able to follow them. In this situation a radar vectoring is provided to the first flight plan point; this is an omnidirectionnal departure.

An omnidirectionnal departure clearance must contains the following elements:
- A heading to follow after departure : eg. Runway track / Heading 320
- The departure runway ; eg. 26R
- The initial altitude or flight level : eg. 5000ft
- The squawk code : eg. 1000

A correct readback of allways required but the controler must be vigilent with omnidirectional departure clearances readback due to the rarity of these and the profeciency of pilots to understand them.
