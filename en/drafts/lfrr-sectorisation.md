# Brest FIR Sectorisation

This page provides an overview of the sectorisation within the **Brest Flight Information Region (FIR)**. It displays the different air traffic control sectors that make up the FIR, including:

* **Area Control Centre (ACC) sectors**
* **Upper Area Control Centre (UAC) sectors**
* **Approach (APP) sectors**

The sectorisation shown on this page is intended to help users understand how the Brest FIR is divided for en-route and approach air traffic control operations, providing a clear view of the responsibilities and boundaries of each sector.
