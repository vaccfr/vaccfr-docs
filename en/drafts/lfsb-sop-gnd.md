## Pushback Procedures
**Stands 1–37, 40–42, 43A–45, 47–48,** and **F1–F22** require pushback.

**Stands 38, 39, 43,** and **46** require pushback for certain aircraft types, depending on the aircraft and stand limitations.

## Taxi
Bale-Mulhouse has a **simple taxiway system**, consisting of a **parallel taxiway running alongside the runway and connecting to the aprons**.
 
### Main Apron
The **Main Apron** uses a system of **blue and orange taxi lines** to assist with ground traffic management.

* **Aircraft with a wingspan below 36 m:**
  * Enter the apron via the **blue taxi line**.
  * Exit the apron via the **orange taxi line**.
* **Aircraft with a wingspan of 36 m or more:**
  * Enter and exit the apron via the **yellow taxi line**.

![lfsb_-_orange_blue_line.png](/doc-atc/lfee/lfsb/lfsb_-_orange_blue_line.png =90%x)

### Code F Restrictions
Please note that **certain taxiway restrictions apply to Code F aircraft**, as indicated in yellow (**A388, B748, AN124, and C5M**).

> **Taxiway A is unavailable to Code F aircraft** when a Code F aircraft is taxiing on **Taxiway B between F and L**. Additionally, **Code F aircraft must use the designated CAT III holding points**.
{.is-warning}

![lfsb_-_code_f_limitations.png](/doc-atc/lfee/lfsb/lfsb_-_code_f_limitations.png =90%x)

## Holding Points
Multiple holding points are available along the active runway at Bâle-Mulhouse, allowing departures to be positioned at different locations depending on the situation.

Controllers should consider the aircraft type, traffic situation, and runway distance available when determining the most suitable holding point. Aircraft do not necessarily need to taxi to the full length of Runway 15/33 if a suitable intermediate holding point can be used.

When practical, use intermediate holding points to distribute departing traffic along the runway and reduce unnecessary runway occupancy or taxiing. Pilots should be advised of the available takeoff distance (TORA) when using an intermediate departure position.
